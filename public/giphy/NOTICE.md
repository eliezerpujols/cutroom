# GIPHY attribution assets

The two PNG marks are unmodified official static horizontal logos from
https://media.giphy.com/giphy-attribution-marks.zip, linked by GIPHY's API docs.
GIPHY retains its trademark rights. These assets provide provider attribution
inside Cutroom; they do not imply endorsement or a license to GIPHY media.

Light mode uses the transparent mark with CSS-darkened lettering, overlaid with
the unchanged color icon region from the same mark. Dark mode uses the original
transparent mark directly. The downloaded PNG files are preserved unmodified.
